# 首页约束

修改首页轮播、推荐抽样或继续观看时阅读本文件。

## 候选与轮播

- 每个应用/账号会话按库总数加权，最多抽取八个 Movie/TV 根节点或 Video 个人视频；排除 Directory、Season、Episode。分页请求保留 `ancestor_guid`，不加载完整目录。
- 轮播集合在导航和播放返回时保持稳定。账号切换时取消请求并拒绝旧响应。
- 使用一个可取消的八秒计时器；悬停、最小化、离开首页和播放时暂停，恢复后重新计时。切换约 180 ms 淡入；减少动态效果时直接切换。
- 图片共用 PosterLoader 的 64 MiB 位图预算；大海报解码最多 1600×900，只预加载下一项。首轮库查询与元数据查询并发最多两个。冷启动时逐步发布候选和详情，首图不等待全部详情；保持抽样顺序并拒绝已取消账号的响应。
- 从缓存启动时保留已有画面；高清背景加载时保留已解码预览，不额外下载预览图。

## 继续观看与布局

- 继续观看读取 `/play/list`，保持服务器顺序和实际记录 GUID；续播位置以 `/play/info` 为准。最多两个进度请求并发，优先首页前十项；确认结果按服务器顺序渐进显示，完整历史分批刷新。部分结果不记为成功缓存；刷新时保留已有卡片。
- 首页继续观看只显示最近十条；“全部”列表使用 `GridView` 并独立保存平滑滚动状态。推荐和继续观看区域分别加载、报错和重试。
- 按客户区剩余高度适配大海报与继续观看卡片；在最小 960×640 窗口内完整展示两区。首页不纵向滚动，继续观看只横向滚动；全部记录使用独立虚拟化网格。
