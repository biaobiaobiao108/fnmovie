# 播放器约束

修改播放器、libmpv、进度控件、附属窗或全屏行为时阅读本文件。

## libmpv 与窗口

- Windows 使用 `resources/windows-amd64/player/libmpv-2.dll`，不得启动或重新加入 `mpv.exe`。绑定通过 Windows DLL 导出和 purego 调用。
- 创建实例时固定 `config=no`、应用配置目录、`wid=MyGoSurface`、`vo=gpu-next`、`gpu-context=d3d11`、`hwdec=auto-safe`、`ao=wasapi`、`audio-channels=auto-safe`。不要启用压缩音频直通、不要强制音轨语言，并保留 libmpv 默认网络缓存。
- 播放控件使用 MyGo 原生 UI 透明附属窗，设置 `Parent` 和 `SkipTaskbar`。视频绘制区域位于独立播放器窗口内；标题/返回位于播放器窗口客户区顶部，控制位于底部。不要使用全屏控件面板或留下紫色色键。控件显示淡入，闲置 2.5 秒淡出；退出、最小化、缩放和全屏时同步附属窗与 libmpv 生命周期。
- 播放、快退、快进按钮组相对播放器区域严格居中，不受两侧控件宽度影响。
- 自动显现使用 `ShowInactive`；闲置淡出不得无条件抢回主窗口焦点。只有控件实际持有焦点时才恢复播放快捷键。
- 只有真实位置或尺寸变化时才调整视频和附属窗几何，不随进度刷新或鼠标活动重复定位。瞬闪回归应检查连续视频帧，不能只验证播放结束后的单帧截图。
- 播放选项菜单使用独立透明附属窗，标准尺寸 300×330 DIP，小窗口按可用空间缩小。长轨道名单行截断；菜单展开不得移动或扩展底部控制窗。菜单同步最小化、缩放、全屏和关闭生命周期。

## 弹幕

- 弹幕数据来自 danmu_api v2 协议（`/api/v2/match`、`/api/v2/search/anime`、`/api/v2/bangumi/{id}`、`/api/v2/comment/{id}?format=json`），默认服务器为飞牛地址主机的 9321 端口，可在播放器的弹幕面板中覆盖。
- 弹幕通过 libmpv 的 secondary subtitle 轨呈现：生成的 ASS 文件写入临时目录，`sub-add` 选中后设置 `secondary-sid`，再恢复用户原有的主字幕。切换弹幕只改变 `secondary-sub-visibility`，不得改动主字幕选择。
- 设置变更先重写 ASS，再通过 `sub-reload` 生效；自动匹配按文件名（优先 `file_name`）匹配，匹配到番剧但集数不一致时按 `EpisodeNumber` 从剧集列表选取。搜索选集只影响当前播放会话。
- 弹幕开关、字体倍率、不透明度、滚动时长、覆盖范围、位置（顶部/居中/底部）、时间偏移、滚动/顶部/底部类型和描边保存在 `settings.json` 的 `danmaku` 字段。面板宽度 460、高度 580，按窗口可用空间收缩，长列表在面板内滚动。
- 播放结束、切换影片或取消请求时必须取消匹配/搜索请求、清理临时 ASS 目录，并拒绝过期响应。弹幕加载不得阻塞视频启动或抢占主窗口焦点。

## 进度跳转与过渡

- 进度跳转通过 libmpv 异步命令提交。控件立即保留最新目标，拒绝旧请求和旧时间戳快照；收到命令确认、退出跳转/缓冲且到达目标附近后恢复真实进度。拖动只在释放时提交，重复跳转以最新请求为准。状态提示预留固定空间，播放记录始终使用真实播放位置。
- 全屏进入/退出使用约 160 ms 原生淡出、切换、淡入，控件同步透明度；只切换一次窗口几何，不逐帧缩放视频。减少动态效果时直接切换；取消、最小化和退出播放时恢复窗口透明度。
- 详情页准备播放只在触发按钮内显示加载动画并保留取消操作。播放覆盖层尺寸需包含控制栏完整圆角边框和上下留白，避免窗口裁剪。
