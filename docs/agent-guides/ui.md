# 页面与交互约束

修改页面布局、列表、滚动、导航或动画时阅读本文件。

## 详情与演员页面

- 电影和剧集标题位于右侧简介上方，预留两行并对齐海报顶部；超过两行省略。海报下方一行放小尺寸播放、喜欢按钮，海报和操作行整体垂直居中。演职人员按可用宽度换行，默认最多两行，更多人员可展开并随详情纵向滚动；元数据和简介间留固定距离。简介按窗口空间最多显示八行，异步数据不能推动布局。
- 简介预览按完整行省略；不要用滚动窗口裁出半行。用户展开后可阅读完整简介。
- 准备播放时，在原播放按钮内显示加载动画；再次点击可取消，不叠加加载弹窗。季度和分集与详情信息共用虚拟化滚动容器。
- 剧集列表使用无边框背景的播放图标和清晰的整行点击区。演员页的头像与身份信息融入页面，不使用铺满宽度的白色介绍卡片。

## 列表与滚动

- 媒体卡片使用 `ui.GridView` 虚拟化；长列表使用 `ui.List` / `ui.GridView`，只构建可见行。派生列表仅在目录数据、导航范围、搜索或筛选变化时重建；不要滚动时全量重建列表。
- 海报统一经过 `PosterLoader`；不要在卡片构建函数启动无界 goroutine，也不要恢复逐卡片进入动画。
- 纵向滚动复用 `advanceSmoothScroll` / `bindSmoothScroll`，各区域独立保存位置和动画状态。普通滚轮平滑推进，精确输入及减少动态效果时直接跟手，边界保留原生冒泡。
- 不得硬编码 30/60 FPS 上限；滚动帧交给 MyGo/Windows 显示调度。

## 视觉与动效

- 全项目禁止 Tooltip、悬停说明气泡和自动弹出的帮助浮窗。图标按钮使用 `Label` 提供辅助技术语义；功能菜单只在用户点击时展开。
- 影视库图标使用继承导航颜色的单色线条 SVG，不使用彩色拟物 Emoji。
- 页面导航（目录、电影/剧集详情、演员详情和返回）使用单个稳定 Key 的内容容器，约 160 ms、最多 6 DIP 的轻微位移与淡入。按钮和筛选使用约 120 ms 颜色过渡。优先使用 MyGo `ElementTransition` 并遵循系统减少动态效果偏好；动画期间才请求显示调度帧，不启动逐帧 goroutine，不做逐卡片/逐集进场，不复制大列表做退出动画，也不通过动画改变布局尺寸。异步元数据更新不得重触发页面进场。
