# 媒体数据与缓存约束

修改飞牛媒体查询、详情数据、异步加载或缓存时阅读本文件。

## 媒体层级与接口

- 飞牛媒体列表可能混合 `Movie`、`TV`、`Season`、`Episode`。一级卡片只显示电影和剧集根节点；季度通过 `GET /season/list/{TV.guid}` 加载，分集通过 `GET /episode/list/{Season.guid}` 加载。演员通过 `POST /person/list/{item.guid}` 读取。层级变化时先核对服务端结构，不按标题猜分组。
- 普通影视库查询必须按库传 `ancestor_guid`。首页分页也保留此条件；全局搜索只传关键词，清空后恢复原浏览范围。
- 电影/剧集详情元数据、季度和演职人员独立返回；季度先到时立即加载分集，迟到元数据不得覆盖已加载的演员或季度。分集详情最多沿父节点查询两层。
- 剧集演职人员先查询真实 TV GUID；根节点为空时，按服务器返回的当前 Season GUID、首集 Episode GUID 顺序补查。限制请求数量并拒绝过期季度响应。空数据或错误应显示状态，不隐藏整个演职人员区域。
- 详情、分集、演员和播放源请求传入 `Context`；离开页面、切换账号或取消播放时真正取消请求并拒绝旧响应。

## 缓存与资源

- 海报原图按服务器图片 URL 哈希存入用户缓存目录，最多 512 MiB、30 天过期；解码最多两个 worker。UI 位图 LRU 默认 64 MiB（计入 mip 层），最多两个 worker、64 个待处理任务。
- 播放时清空位图缓存、暂停并丢弃待处理海报任务，过期解码不得回填；返回后复用磁盘原图。检查内存时区分 Go 堆、进程工作集和原生/GPU 开销；不要通过降低视频画质或禁用默认网络缓存压数字。
- 目录/搜索内存状态最多保留最近八个范围；退出详情时释放分集派生缓存。目录和详情元数据缓存到用户配置目录，不存登录令牌或密码。
- 演员作品缓存按服务器/账号/GUID 隔离，最多八个范围、每范围 120 项、五分钟过期。先显示缓存并后台刷新；退出账号时清空。缓存上限不得截断完整结果。
