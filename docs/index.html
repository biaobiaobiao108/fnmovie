真实客户端界面

片库里的样子，就是你看到的样子。

以下截图均来自哞哩影院原生客户端，使用真实测试片库内容。页面里的影片海报和信息没有经过生成或替换。

01 / 电影

海报排好，找片更直接。

按影视库浏览电影，扫一眼海报、评分和年份，再打开感兴趣的影片。

02 / 电视剧

电影和剧集，各有各的入口。

独立查看剧集库，海报和评分一目了然。

03 / 搜索

记得片名，就直接搜。

用片名缩小结果，少翻几页海报。

04 / 影片详情

了解影片，再决定什么时候播放。

详情页保留简介、评分和演职人员，也可以直接收藏或开始播放。

05 / 剧集详情

看到第几季、第几集，都清清楚楚。

按季度切换，集名与简介在同一页浏览，点一集就能进入播放。

测试片库的具体影视内容仅用于界面展示；连接自己的飞牛影视后，会显示账户有权限访问的媒体库。

三步开始

准备好自己的片库，就可以开看。

下载 Windows x64 版本，在应用中填写飞牛影视服务器地址和账户。登录后选择影视库，开始浏览。
